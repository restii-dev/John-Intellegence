# John Intellegence Chat Archive

This folder is for saved conversations.

How it works:
- Open the main page (index.html)
- Click **Chat Folder** and select this `chats/` directory (or any folder)
- Every conversation will be saved as a Markdown file here
- Each file includes the full chat, timestamp, theme, emotion, and origin URL

You can also manually drop exported chats into this folder and commit them.
