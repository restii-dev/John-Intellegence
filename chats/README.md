# John Intellegence Chat Archive

This folder is intended for saved conversations from the local AI.

## How to use
1. Open the index.html (locally or via GitHub Pages)
2. Click the **Chat Folder** button
3. Select this `chats/` directory (or any folder on your machine)
4. Every conversation will be written as a Markdown file here with:
   - Full chat history
   - Timestamp
   - Current theme & emotion
   - Origin URL (where the chat was started)
   - Browser info

You can commit these chat files back to the repo whenever you want so they are visible to both of us.
